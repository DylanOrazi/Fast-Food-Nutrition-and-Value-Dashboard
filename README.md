Fast Food Nutrition & Value Dashboard

Project Overview:
The Fast Food Nutrition & Value Dashboard is a Tableau project that analyzes a fictional fast-food meal dataset. The project compares restaurants and meal categories by nutrition, price, value, and meal scoring metrics.

Tools Used:
- Tableau
- Excel / CSV
- Data visualization
- Dashboard design
- Project documentation

Main Files:
- fast_food_nutrition_dataset.csv
- Fast_Food_Nutrition_Value_Dashboard.twbx
- Project Findings.txt
- README.txt

Dataset Overview:
The dataset contains 200 fictional fast-food meal records.

The dataset includes:
- Restaurant
- Meal name
- Meal category
- Calories
- Protein
- Carbohydrates
- Fat
- Sodium
- Sugar
- Price
- Calories per dollar
- Protein per dollar
- Health score
- Value score
- Cheat meal score

Tableau Worksheets Created:
1. Average Calories by Restaurant
2. Average Protein by Meal Category
3. Average Sodium by Restaurant
4. Health Score by Meal Category
5. Average Price by Restaurant
6. Calories vs Price Scatterplot
7. Top 10 Best Protein-per-Dollar Meals
8. Value Score by Meal Category

Dashboards Created:
1. Nutrition Overview Dashboard
2. Value & Meal Comparison Dashboard

Dashboard 1:
Nutrition Overview Dashboard

This dashboard compares fast-food meals by calories, protein, sodium, and health score. It focuses on nutrition patterns across restaurants and meal categories.

Dashboard 2:
Value & Meal Comparison Dashboard

This dashboard compares meals by price, calories, protein-per-dollar, and value score. It focuses on meal value, cost, and overall comparison.

How to Use:
1. Open the Tableau packaged workbook file.
2. Review the Nutrition Overview Dashboard.
3. Review the Value & Meal Comparison Dashboard.
4. Use the worksheets to explore individual charts.
5. Refer to the Project Findings file for a summary of insights and skills learned.

Design Notes:
Colors were chosen based on metric meaning:
- Orange for calories
- Green for protein
- Red for sodium
- Teal for health score
- Blue for price
- Gold for value score

Project Purpose:
This project was created to practice Tableau dashboard development using a fun and easy-to-understand dataset. The goal was to build a complete visualization project with multiple worksheets, two dashboards, and supporting documentation.
